设计概览

Space Intruders 前端原型 · 架构说明

本文档总结了演示项目的核心目标、功能范围、文件组织方式，以及关卡/敌人配置的结构设计。 透过轻量的配置驱动方案，我们可以在无需额外构建链的前提下，快速定义和扩展关卡内容。

项目目标与范围

当前版本聚焦于构建一个可在 Chrome 浏览器本地直接打开的 Space Intruders 克隆版，实现基础的飞船控制、敌人阵列、弹幕与碰撞判定，验证配置化关卡的可行性。

  • 运行环境：双击 index.html ，无需本地服务器。
  • 关卡管理：基于 src/config/levels 目录的模块化配置文件。
  • 敌人定义：集中于 src/config/enemies.js，支持不同形态和数值。
  • 核心体验：单人射击、得分统计、关卡切换、暂停/文档查看。

文件组织

前端结构

  • index.html：页面骨架、HUD、文档面板触发按钮。
  • styles/main.css：整体布局、配色、设计文档面板样式。
  • src/main.js：入口脚本，初始化游戏并控制文档面板。

游戏逻辑

  • src/core/：游戏主循环、关卡工厂、场景管理。
  • src/entities/：玩家、敌人基类与子类、子弹、特效。
  • src/systems/：渲染、输入、碰撞系统。
  • src/utils/loader.js：加载敌人/关卡配置数据。

关卡配置结构

关卡以模块化文件形式存在 src/config/levels，每个文件导出一个对象。 关卡列表通过 index.js 汇总，加载顺序即游玩顺序。 

export default {
  id: 'level-1',
  name: 'Formation Primer',
  description: '标准开局阵列，帮助玩家熟悉节奏。',
  origin: { x: 70, y: 80 },
  spacing: { x: 44, y: 36 },
  grid: {
    rows: 5,
    cols: 11,
    layout: [
      ['scout', null, ...],
      ['grunt', 'grunt', ...],
      ...
    ]
  },
  pace: {
    baseStepInterval: 900,
    accelerationFactor: 0.94,
    horizontalStep: 18,
    verticalStep: 28,
    fireInterval: 1700,
    simultaneousFireCap: 2
  },
  player: {
    lives: 3,
    fireCooldown: 260
  }
};

通过调整 origin 和 spacing 可控制阵列布局； 修改 pace 即可改变移动和射击节奏； layout 数组使用敌人类型 ID 或 null 表示留空。

敌人类型与继承

敌人定义集中在 src/config/enemies.js，每个条目包括生命值、射速、得分、渲染矩阵等数据。 运行时通过 LevelFactory 创建不同的子类（如侦察、重装、头目），以便扩展特殊行为（摆动、缓动、护盾等）。

  • EnemyBase：实现生命、冷却计时、网格坐标、得分等基础逻辑。
  • 子类可在 update() 中调用 applyOffset 叠加独特运动。
  • 新增敌人时仅需补充配置与对应子类（若无特殊行为可直接复用基类）。

系统协作流程

  1. 初始化：入口脚本加载配置，实例化 Game、Renderer、InputManager。
  2. 关卡载入：LevelFactory 基于配置创建敌人阵列，注册至 Scene。
  3. 主循环：Game 驱动 Level 和 Scene 更新，随后渲染当前帧。
  4. 碰撞检测：CollisionSystem 处理子弹与实体交互，触发得分与生命变化。
  5. 状态切换：依据敌人清空或玩家生命耗尽，切换到胜利/结算状态，并等待输入继续。

扩展与后续路线

  • 在 src/config/levels 增加新文件即可扩充更多关卡。
  • 在 src/entities/types 创建新子类，可实现蛇形、俯冲等特殊动作。
  • 预留 Effect 与事件钩子，可引入爆炸动画、音效模块。
  • 通过 localStorage 追加高分榜；或添加手柄/Gamepad 输入模块。

本地运行说明

在 macOS 上直接双击项目根目录的 index.html，选择 Chrome 打开即可。 若需要调试 Fetch 或跨源资源，可选用 python3 -m http.server 启动本地服务器，但对试玩并非必需。

若要验证关卡配置修改，可刷新页面或在控制台调用 SpaceIntruders.game.start() 重新加载。
